> Written when there were 23 stages. The board now shows seven (`docs/handoff/STATE.md`, "The stage list"); the 23 keys still exist in the database.

The owner said: _"don't forget a single thing of what I said."_ This is every ask, in his order, mapped
to what exists and how far it has been **proven**. Status words mean exactly this:

- **Proven** — driven in a real browser and the database rows checked (`pnpm e2e`, or the DB tests).
- **Tested, network mocked** — logic and DB state proven; the call to Google/Resend/Voice is simulated
  because it needs real credentials or accounts we don't have here.
- **Not proven** — built, but not yet confirmed working.
- **Not built** — said so plainly.
